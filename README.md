# Ikonenatelier Miomir

Webseite für handgemalte orthodoxe Ikonen in Eitempera und echtem Blattgold – mit Galerie, Formaten, Porträts, Künstlerseite und Anfrageformular.

**Vorschau:** https://appworkshopdb.github.io/ikonenatelier-miomir/

## Dateien

- `index.html` – die komplette Webseite
- `bilder/` – Fotos der Werke und des Künstlers
- `anfrage.php` – verschickt Anfragen aus dem Formular samt Bildvorlagen per E-Mail

## Hinweis zum Formular

Auf GitHub Pages läuft das Formular nur als Vorschau und verschickt nichts, weil GitHub kein PHP ausführt.
Für den echten Betrieb alle Dateien zu einem Webhoster mit PHP hochladen und oben in `anfrage.php`
die Adressen `EMPFAENGER` und `ABSENDER` eintragen.
